# aws-Spotify-End-to-End-ETL-Pipeline
**Spotify End-to-End Data Pipeline on AWS**  An end-to-end AWS Data Engineering project that extracts Spotify dataset, runs ETL using AWS Glue Studio, loads partitioned Parquet data into an S3 Data Warehouse, and catalogues schemas via AWS Glue Crawlers. Enables SQL querying with Amazon Athena and interactive dashboard analytics using QuickSight.
